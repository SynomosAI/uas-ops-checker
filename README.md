# uas-ops-checker

> **状态：RESERVED（占位 · 开放认领）** — 本仓已按平台协议规范建好行业接入四件套骨架，
> 等待具备本域资质的运营方认领并填充真实规则。

把「这架无人机能不能在这儿、按这个方式飞」拆成可核验的属性，让 AI 只做路径提示，不做放行。

## 这个域管什么

机型分类与运营合规路径判定

低空飞行涉及空域管制、实名登记、操控员资质、保险等多重要件，且规则更新频繁。AI 能做的是把该走哪条路、缺哪个件摆清楚，放行权始终在管制单位。

## 属性清单

| 属性键 | 类型 | 说明 |
|---|---|---|
| `uas.aircraft_class` | enum | 按民用无人驾驶航空器运行安全管理规定的重量/性能分类 · 取值 micro/light/small/medium/large |
| `uas.registration_status` | enum | 实名登记状态 · 取值 registered/unregistered/exempt |
| `uas.operator_cert` | enum | 操控员资质与当前有效性 · 取值 none/training/certified/suspended/revoked |
| `uas.flight_zone` | enum | 拟飞空域类别，须以空域管理单位实时公布为准 · 取值 open/controlled/restricted/prohibited |
| `uas.liability_insurance` | enum | 第三者责任险投保情况 · 取值 insured/uninsured/not_required |

## 本域红线（不可逾越，机器可读）

1. 禁飞区与管制空域不得输出任何形式的放行性表述
2. 未完成实名登记或操控员资质失效的，不得给出可飞结论
3. 不下适航审定结论，空域状态以管制单位实时公布为唯一依据

> 红线在 `gate-map.json` 中均有对应阻断规则。平台校验器会检查「每条红线都有规则覆盖」，
> 缺失即校验失败——**制度与系统不允许不同步**。

## 行业接入四件套

| 文件 | 作用 |
|---|---|
| `domain.manifest.json` | 本域声明：属性清单、签发方要求、有效期、红线 |
| `gate-map.json` | 本域「什么动作要多少摩擦」：silent / warn / confirm / block / require-owner |
| `privacy.json` | 本域隐私声明：默认关闭、最小必要、可撤回、可删除 |
| `checker` | 本域核验器（MCP 工具，**只出示核验，不下判定**） |

## 核心原则

**平台只当擂台，不当货架。** 本域的核验器只回答「这条声明是否可核验、缺什么要件」，
不回答「这件事是否合规、该不该做」。判定权在本域的资质方、监管方与人。

**隐私是准入条件，不是整改事项。** 缺失 `privacy.json` 或任一必填字段不符，
符合性校验直接失败——不是警告，是拒绝接入。
